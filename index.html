Local data, privacy, and limitations

API keys and personal camera entries stay in Oversee's local application-data folder and are excluded from diagnostic exports. Most provider keys remain server-side; Cesium ion and Google map credentials are delivered only to this local interface because those tile services require browser-side tokens. Restrict both credentials at their provider before sharing the app.

Map signals come from best-effort public sources and can be delayed, cached, incomplete, or unavailable. Use each official source link before making an important decision.
